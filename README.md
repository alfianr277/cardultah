# 🎂 Kartu Ucapan Ulang Tahun Interaktif

Kartu ucapan ulang tahun berbentuk buku digital. Buku awalnya tersegel, jadi harus diketuk beberapa kali sebelum bisa dibuka. Setelah terbuka, ada halaman-halaman berisi foto kenangan dan ucapan, ditutup dengan kue ulang tahun, confetti, dan kembang api.

🔗 **Lihat di sini:** LINK-ANDA

## ✨ Fitur
- Buku tersegel dengan efek suara saat segel diketuk dan dibuka
- Buku dua lembar dengan animasi membalik halaman dan suara kertas
- Foto kenangan lengkap dengan tanggal di setiap halaman
- Lagu ulang tahun yang diputar saat buku dibuka
- Halaman penutup dengan kue, lilin yang bisa ditiup, confetti, dan kembang api

## 📁 Struktur
```
index.html   → halaman utama (HTML, CSS, dan JavaScript)
img/         → foto kenangan (foto1.jpg, foto2.jpg, dst.)
audio/       → lagu latar (lagu.mp3)
```

## 🛠️ Teknologi
HTML, CSS, dan JavaScript murni tanpa framework. Efek suara dibuat dengan Web Audio API, animasi dengan CSS 3D, dan efek partikel dengan Canvas. Di-hosting dengan GitHub Pages.

## 💌 Dibuat dengan cinta
Proyek pribadi sebagai kado ulang tahun.
